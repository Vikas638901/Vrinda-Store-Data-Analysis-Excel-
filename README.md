# Vrinda Store Data Analysis

## Project Overview
An Excel-based data analysis project focused on exploring Vrinda Store's sales and order data through dashboards and visualizations.

## Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Interactive slicers and filters

## Analysis Included
- Sales vs. Orders
- Men vs. Women
- Order Status
- Top 10 analysis
- Sales channels

## Project File
`Vrinda Store Data Analysis.xlsx`

## Objective
To organize sales data, analyze business trends, and present insights in an easy-to-understand dashboard.
